WATTWISE
========

WattWise is a simple electricity consumption monitoring
and energy-saving web application.

PROJECT FEATURES
----------------

1. Home Page
   Introduction to the WattWise application.

2. Dashboard
   Displays estimated monthly electricity cost,
   daily usage and potential savings.

3. Energy Analyzer
   Allows users to select an appliance and enter:
   - Hours per day
   - Days per month

   It calculates:
   - Monthly energy consumption
   - Daily energy consumption
   - Estimated monthly electricity cost
   - Potential savings

4. Energy Simulator
   Allows users to enter their monthly electricity usage
   and simulate a percentage reduction.

   It displays:
   - Energy saved
   - Money saved
   - New monthly usage

5. Insights
   Provides practical energy-saving tips for users.
